# Supplier Atlas

Stitch project: https://stitch.google.com/projects/9079318459213521775

Paraxanthine design screen: `3517ee94a79b49719128ea36c999b511`.
Retatrutide companion screen: `d67aecf6dcb645b98b934f439302fa5c`.

The original rendered reference was captured and imported into Stitch, then redesigned. The Retatrutide companion was developed as a variant. Production code follows those compositions while retaining the original datasets, real navigation targets and working features. Generated example copy, speculative pages and invented version labels are excluded.

## Visual system

- Warm paper `#f5f4ee`, near-white records `#fffefa`, forest ink `#242e29`, muted text `#626e65` and fine rules `#d9ddd2`.
- Paraxanthine uses rust `#9f432d`; Retatrutide uses teal `#1b6259`.
- Large editorial serif titles, system sans-serif interface text, and restrained monospace folios. System fonts keep the site independent of external font services.
- A quiet navigation rail and two-column supplier cards on desktop become compound tabs and a single-column directory on phones. A mobile directory shortcut, visible labels, keyboard focus, live result counts and reduced-motion support remain part of the interface.
- Compact facts lead into expandable full research details. Warnings and restrictions remain visible. Grid/list views and bidirectional sorting support comparison.

## Linework reference

The original SVG illustration borrows the oval rings, fine spokes and isolated rectangular marks of the 1924 Ceride-i Adliye issue 27 radial ledger, with the controlled density of Emma Kunz's woven halo as a secondary reference. It is ornamental, with no numerical encoding. No scan, inscription, decorative script or invented chemical structure is reproduced.

## Delivery verification

Browser checks cover the original record counts, search, filters, empty states, sorting, layout switching, JSON export, phone widths of 390px and 320px, and browser errors. Retatrutide also covers original dataset equality, legacy saved notes, note persistence, import/export, the existing HTML alias, and functioning standalone HTML downloads that exclude working notes.
